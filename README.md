# FA26-IS601851-MidTermProject-Enhanced_Calculator_CLI

## Arithmetic operations

The calculator supports `add`, `subtract`, `multiply`, `divide`, `power`,
`root`, `modulus`, `integer_division`, `percentage`, and
`absolute_difference`. Each operation accepts two numbers. Percentage
calculates `(first / second) * 100`; division, modulus, integer division, and
percentage report an error when the second number is zero.

Start the command-line calculator with `python main.py`, then enter an
operation name and its two operands when prompted. Use `help` in the
calculator to see the available commands.
